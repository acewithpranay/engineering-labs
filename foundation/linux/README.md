# Linux

Hands-on work around Linux systems, with a focus on understanding how the operating system behaves and how to troubleshoot it.

This is not meant to be a Linux command reference. The useful parts here come from experiments, failures, and investigations.

## Areas

* Processes and signals
* Filesystems and storage
* Users, groups, and permissions
* Networking
* Services and systemd
* Resource management
* Troubleshooting
* Security

More experiments will be added as I work through the topics.
