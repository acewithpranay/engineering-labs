# Engineering Labs

This repository is where I keep experiments, notes, troubleshooting work, and small implementations while working through systems and platform engineering topics.

The goal isn't to collect tutorials. I want to understand how things actually work, test that understanding, and keep the useful parts.

## Areas

### Foundations

* Linux
* Networking
* Scripting and automation
* System design

### Platform and infrastructure

* Docker
* Kubernetes
* Terraform
* Cloud
* GitOps
* Observability

### Security

* Identity and access
* Secrets
* Policy as code
* Container and software supply chain security

### AIOps

* Incident analysis
* Anomaly detection
* Automation
* AI-assisted operations

## How I use this repository

Most work starts here as an experiment.

Some things will stay small. Others may grow into standalone projects when there is enough engineering depth to justify their own repository.

For experiments, I try to record:

* what I was trying to understand
* what I tested
* what happened
* what I learned
* what I'd do differently in a real environment

The repository will change as I learn and build.
